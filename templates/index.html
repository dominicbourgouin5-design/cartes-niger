STRUCTURE DU TEMPLATE ======================================== Les colonnes sont : A = N_ID B = Nom C = Prenoms D = Fil_de E = Et_de F = Date_naissance G = Lieu_naissance H = Profession I = Taille J = Adresse NE CHANGE PAS les noms des colonnes. NE DÉPLACE PAS les colonnes. NE RENOMME PAS les colonnes. ======================================== 2. N_ID ======================================== Créer 200 identifiants uniques. Format obligatoire : N°72101/25/ANC. Puis : N°72102/25/ANC. N°72103/25/ANC. Pour 200 lignes, utiliser une série unique allant par exemple de : N°72101/25/ANC. à N°72300/25/ANC. ======================================== 3. Règles très importantes : - Le NOM doit être un véritable nom de famille. - Le PRÉNOM doit être un véritable prénom. - NE JAMAIS mettre le même mot dans Nom et Prenoms. - Interdit par exemple : Nom : DAOUDA Prenoms : DAOUDA Nom : MALAM Prenoms : MALAM Nom : ADAMA Prenoms : ADAMA Ce type de doublon est interdit. Format : NOM DU PÈRE + PRÉNOM(S) DU PÈRE RÈGLE FAMILIALE OBLIGATOIRE : Le père et l'enfant doivent avoir EXACTEMENT LE MÊME NOM DE FAMILLE. Autre exemple : Nom enfant : ABDOU Prenoms : MOUSSA Fil_de : ABDOU IBRAHIM Correct. NE JAMAIS faire : Nom enfant : ABDOU Fil_de : GARBA IBRAHIM C'est incorrect. Le prénom du père doit être différent du prénom de l'enfant lorsque cela est possible. Éviter absolument les choses absurdes comme : Nom enfant : DAOUDA Prenoms : DAOUDA ou : Fil_de : DAOUDA DAOUDA ======================================== 5. ET_DE = MÈRE ======================================== La colonne E « Et_de » correspond à la MÈRE. Elle doit contenir : NOM DE FAMILLE DE LA MÈRE + PRÉNOM(S) DE LA MÈRE IMPORTANT : La mère possède son PROPRE NOM DE FAMILLE. Dans les données, le nom de la mère doit être différent du nom du père et de celui de l'enfant. Exemple : Enfant : ADJOVI MARC Père : ADJOVI JEAN Mère : DOSSOU MARIE C'est cohérent. DATE DE NAISSANCE ======================================== Colonne F = Date_naissance. Format obligatoire : JJ/MM/AAAA Exemple : 14/03/1998 Les dates doivent être réalistes. Ne pas mettre des dates impossibles. ======================================== 9. LIEU DE NAISSANCE ======================================== Colonne G = Lieu_naissance.
